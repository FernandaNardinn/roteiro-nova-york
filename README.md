# Roteiro Nova York

Site do roteiro de viagem para Nova York (26 nov – 2 dez 2026): timeline por dia, mapas, contatos, ingressos, dicas e modo de edição.

É um site estático: um único `index.html`, sem build.

## Publicar no Vercel

1. Importe este repositório em https://vercel.com/new
2. Framework Preset: **Other**. Não precisa de comando de build nem de pasta de saída.
3. Clique em **Deploy**.

## Sobre as edições

No Vercel, o que a pessoa muda no modo **Editar** fica salvo no navegador do próprio celular (localStorage). Cada pessoa vê as próprias mudanças.

## Instalar como app

No iPhone (Safari): botão Compartilhar → **Adicionar à Tela de Início**.
No Android (Chrome): menu ⋮ → **Instalar app**.
Depois da primeira abertura com internet, o roteiro abre mesmo sem sinal.
